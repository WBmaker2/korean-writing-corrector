# Changelog

## [0.2.0] - 2026-11-09

### Changed
- Full UI/UX redesign for usability: paper-toned theme, grouped toolbar, legend, char/word counts, empty states, themed browser surfaces, responsive layout.

### Added
- Initial Korean writing/grammar corrector web app.
- Phase 2: expanded rules, Vitest tests, context filters/priority, user ignore, debounce, undo/redo, diff, export formats, responsive layout, deploy configs.
- Rule-based spelling, spacing, grammar checks.
- Highlight editor, suggestion panel, one-click apply, apply all.
- Statistics and learning mode.
- Web Worker analysis, localStorage persistence, export.
